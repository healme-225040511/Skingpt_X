# SkinGPT-X self-evolving memory v1: exploratory evaluation

## Protocol

- Server: `31902`, 2 x NVIDIA RTX A6000.
- Frozen diagnosis model: Qwen3-VL-8B-Instruct.
- Existing 5,533 paired Q100 cases were split label-blind by a deterministic SHA-256 rule into rule acceptance (25%), gate development (25%), and held-out evaluation (50%).
- Rule sources were restricted to the first 80% of each immutable training stream.
- This is an exploratory sanity check, not a fresh independent confirmation, because these 5,533 cases had been inspected in earlier mechanism analyses.

## Knowledge snapshot audit

- 537 contrastive rule proposals from four datasets.
- 570 generation/repair attempts, including 33 targeted retries or deterministic conflict normalizations.
- Final audit: 537/537 valid rules, 0 missing, 0 malformed JSON, 0 unresolved source-ID or cross-field conflicts.
- Candidate release SHA-256: `7d751b60e2cfa8998662cce9b661c99a42499f67f4af19413b4eba55b510d937`.

## Independent rule acceptance

- 1,346 cases in the acceptance split; 718 had a candidate rule and were re-inferred, while 628 fell back to C100.
- All 718 outputs were unique and valid closed-set predictions.
- Raw candidate-rule effect among the 718 exposed cases: 18 gains, 14 regressions, 18 changed-but-no-correctness-flip, and 668 unchanged; net +4 correct.
- Rule status: 2 active, 7 rejected, 528 provisional.
- Active release SHA-256: `6a088a10c36e8aeee082cfc50e83430ed9077aeef2a04386f804acfcf90d80cf`.

Active rules:

1. Fit17k actinic keratosis vs basal cell carcinoma: 4 exposures, 2 changes, 2 gains, 0 regressions, reliability 0.75.
2. HAM10000 benign keratosis-like lesions vs melanoma: 29 exposures, 2 changes, 1 gain, 0 regressions, reliability 0.667.

## Gate development

- 22/1,390 gate-development cases were covered by active rules.
- One initially invalid closed-set diagnosis was targeted and recomputed; the final audit passed for 22/22 unique outputs.
- The raw active-rule effect was 0 gains, 1 regression, 2 changed-but-still-wrong cases, and 19 unchanged cases.
- No pre-registered gate configuration had positive net benefit while meeting the safety constraints.
- The frozen gate therefore selected the C100 fallback with zero overrides.

## Claim verdict

This first version does not establish that self-evolving knowledge improves recognition. The primary V1 comparison is identical to C100 because the independently frozen safety gate correctly rolled back. Validated rules show a small positive, regression-free signal and clearly avoid the harmful Raw-E behavior, but the effect is not statistically significant and has very low coverage. A publication-grade improvement claim requires a fresh temporal or external test set and a larger independent acceptance/gate cohort.
